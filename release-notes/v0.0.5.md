TLC 0.0.5 — Trust & Contact.

v0.0.4 proved the record. v0.0.5 proves the relationship. This is the usability release: names,
numbers, and a way to reach the Pioneer, all still local-only, still non-custodial, and still
without an INTERNET permission.

The headline is simple. You can now give yourself a handle, add the people you actually support,
save a bank destination once in an encrypted vault, send Support directly, record a Pioneer's Token,
and write to the Pioneer with a purpose before a channel. None of it moves money. All of it stays on
this device.

### A quieter, more premium surface

- **No pink.** The rosewood and rose-mist palette is gone. The app now uses royal blue, azure,
  silver-grey and cool white surfaces, with midnight navy for the icon tile.
- **A new emblem.** A crowned heart with a sprout, drawn as a vector so one master serves the
  launcher icon, the themed icon and the store listing.
- **A simpler shape.** Four tabs — Today, Record, People, Settings — plus a Create sheet for every
  everyday verb. Settings is a destination, not a junk drawer.
- **Better contrast and motion.** The dark theme is midnight ink, not black; motion respects the
  system setting; haptics can be turned off.

### Names, for people and for roles

- **Handles.** Every profile gets a `@handle` at onboarding, validated locally: 2–24 lowercase
  letters, digits, dots or underscores.
- **Two reserved addresses.** `@pioneer` is the official role handle. `@sircollins` is the person
  behind it. Both are reserved, both reach the same desk, and neither can be claimed by anyone else.
- **A real address book.** Add a person, give them a handle and a role, and attach one saved
  destination. People are local records, not accounts.

### The bank vault

- **Save once.** Add a bank, a ten-digit account number and a holder name. The NUBAN check digit is
  validated locally before anything is saved. There is no name enquiry and no network call.
- **Encrypted at rest.** AES-256-GCM with a key generated inside the Android Keystore and never
  exported. The vault is a separate file from the state and the record.
- **Reveal on purpose.** The app shows only the bank name, the last four digits and a fingerprint.
  Revealing the full number is an explicit action, it hides again on its own, and the reveal is
  written to the record.
- **Never in the record.** The full account number never enters the state file, the ledger, a backup,
  a log, a notification, a URL or an export. Only the last four digits and a fingerprint travel.

### Send Support

- **The missing peer flow.** Offer Supportive or Recognition support to a person you know, with an
  optional amount and a reference.
- **Honest by design.** TLC records the offer, the claim and the acknowledgement. A claim is a
  statement, not a settlement. No balance is created and no money moves inside the app.
- **Receptive Mode is respected.** Support is an offer, never an entitlement.

### Pioneer's Token

- **The rename.** "Pioneer dues" is now **Pioneer's Token**, because a token is an offering, not a
  debt.
- **Activation, Reactivation, Courtesy and Joy** go directly to the Concept Pioneer's own account.
  TLC records the intent and the evidence; it never holds the money.
- **The destination is in the vault.** It is revealed only to the payer, only after the token
  exists, and it hides again on its own.
- **Wording under legal review.** The public wording that describes the Contact & Consent Framework
  is still with the lawyer. The label is in the app; the final copy waits for that review.

### Pioneer Desk

- **Purpose first.** Choose why you are writing, see the opening before it leaves the app, then pick
  a channel.
- **Channels that exist.** Telegram opens first, then email and the website. WhatsApp is deferred
  because the founder's Telegram already uses that number. Phone is not published in this build.
- **A local contact log.** Only the fact of contact is kept: purpose, channel and time. Never the
  message.

### What has not changed

- **The record is still the record.** Append-only, hash-chained, flushed before the app says it was
  kept, re-verified on every launch, and read-only when it does not check out.
- **Still no network.** The APK requests no `INTERNET` permission and contains no Play Services, no
  Firebase, no analytics and no proprietary SDK. Nothing leaves the device unless you export or share
  it.
- **Still no custody.** No wallet, no balance, no payment rail, no card data. The app records the
  intent, the instruction and the evidence; the transfer happens bank to bank.
- **No account, no sync, no multi-device merge.** A Co-Steward is still a local persona. Accounts,
  sync, the SEF economy, the remote attestation console and the social layer are the next milestone.

### Proven by the build, not by the README

- The domain, experience and ledger test suites cover handles, reserved names, NUBAN validation,
  vault references, Support lifecycle, contact logging and the v1 → v2 state migration.
- The `foss` channel is checked for Play Services, Firebase and tracking dependencies.
- The release APK is checked for the absence of the `INTERNET` permission and of Play Services
  classes in its dex, and its signing certificate is pinned to the project's key.

### Where it ships

The same signed `tlc-0.0.5-foss.apk` is the artifact for GitHub Releases, F-Droid, Orion Store and
Uptodown. GitHub Releases is the source of truth. The F-Droid metadata is pinned to this commit and
this APK; Orion Store reads the same GitHub release; Uptodown takes the same file through its
developer console. No channel re-signs it: one package id, one signature, one update path.

GPL-3.0-or-later. No analytics, no advertising identifier, no third-party tracking.
