First published build (v0.0.1), superseded by v0.0.2 within the hour and never announced.

What it contained: the core domain invariants, the hash-chained ledger, the `ledger-verify` CLI and
a thin Compose shell, signed with the project's release key.

Two defects were found while verifying the published binary:

- the APK requested the `INTERNET` permission although the release contains no networking code;
- the universal-link filter for `https://tlc.app` was shipped before that host served
  `/.well-known/assetlinks.json`, so it could never verify.

Neither is exploitable, but both weaken a claim the project makes on the store listing. The tag and
its assets stay as published; they are not replaced. Use v0.0.2.
